# 管理员单端与 AI 审计补齐

## 授权与范围

用户确认按最小方案补齐审计，保留明确标注的共享 Demo Admin，暂不新增正式鉴权。不重建项目、不删除没有证据支持删除的模块、不启用原始模型响应持久化。

## 模块保留与清理结论

- 没有发现可确认属于认证员端或客户端的独立应用、页面、角色切换或专用 API，因此本轮没有删除代码。
- 保留管理员的登录、工作台、客户、账单、ESG 查看、风险、AI 排程、审批、模拟执行、审计、设置和全部现有接口。
- `/customers` 是管理员客户管理，不是客户门户；`api-client-react` 是管理员 SDK，不是客户端应用。API、共享业务 Service、Repository、Schema、旧 Provider 代码及历史资料均保留。
- 组件预览 sandbox 不是认证员端/客户端，未删除。
- 演示登录不建立正式身份认证；Repository 工作区一致性检查不是登录用户的工作区授权。未把此限制描述成已解决。

## 实现

### 字段级诊断

新增 `artifacts/api-server/src/lib/receivables/ai-diagnostics.ts`。

阶段：preflight、transport、json、schema、business、safety、projection。

结果：passed、rejected、replaced、not_run。记录允许的字段路径、固定 reasonCode、已与输入匹配的任务 ID；不记录原始值、Zod message、任意输出键名、HTTP 头、异常对象或上下文正文。最多 4000 项，达到上限明确标记 diagnostics_truncated。

`ai-provider.ts` 记录 JSON/Schema/任务集合/策略集合/ESG 匹配/双语合成声明的检查结果；`ai-content-safety.ts` 只增加观察回调，不改变原有拒绝条件、模板或投影规则。记录 ESG 中立投影、服务端通知模板替换及条件式同意约束。

未进入的阶段标为 not_run，不能把前面部分检查通过当作整份输出通过。任何校验失败仍整份拒绝，保留 Rules 回退；不会应用部分输出。

### 快照契约

OpenAPI 及生成类型增加可选 diagnostics、model、modelOrigin=request_config、rawResponseRetained。旧数据无需回填；旧记录缺字段显示“未记录”，不重新解释历史。

模型名称是请求配置，不是供应商响应确认的实际模型。有效和未应用响应的可靠诊断可进入快照；metadata_only 仍不保存返回正文。审批快照附带原审批记录中的 actor，不伪造真实身份。

未改写跨实例租约、版本门禁、数据库行锁、快照前缀防改写规则或审批状态转换。没有数据库 DDL、迁移或回填；只有兼容的 JSONB/API 可选字段。

### 管理员只读审计界面

- `pages/audit-logs.tsx` 保留原筛选、日志、Before/After，增加快照面板和独立 AI 结果标签。
- `components/advice-snapshots.tsx`：选择精确计划版本后，通过已有 GET Hook 获取快照；展示尝试/工作区/计划/风险关联、状态、校验、配置模型、原文留存状态、诊断、有效建议、模板、最终双语通知及语言来源、人工版本、父关系和精确审批关联。
- `lib/advice-snapshot.ts`：安全解析、列表/计划关联检查、审批匹配、留存状态和结果语义。
- 未选择计划不请求；选择后每 15 秒刷新。加载、请求错误/重试、旧记录空列表、损坏内容和关联缺失有独立提示。
- metadata_only 不显示未经校验或未应用的正文。字段按 React 文本渲染，不执行 HTML。
- 通用日志的 Success 保留为原始“日志动作结果”，与 AI 结果分开；Rules 回退不显示为 AI 成功。人工审批状态优先于原生成来源。
- 旧日志不能解析出 AI 结果时显示未记录；旧快照缺留存字段且无明确原文留存标记时显示未知。

没有新增写按钮、角色、认证机制、ESG 自动评级、审批或执行捷径。

## 原始响应策略

**没有启用原始模型正文持久化。**能追溯的是结构化诊断、通过校验与投影后的有效内容、最终通知及人工版本，不是完整原始响应。

未来启用完整原文持久化仍需单独明确确认及访问/保留/敏感内容政策，不能把本轮审计授权当成原文留存授权。

- 测试未连接共享数据库；临时 PostgreSQL 已停止清理。
- 未向共享服务发送 workspace、登录、ESG 查看、导入、重置、审批或执行请求。
- 临时库/内存测试中的生成与审批仅作用于合成夹具。
